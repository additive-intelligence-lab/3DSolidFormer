The dataset contains three-dimensional voxel geometries, nodal loading and displacement constraints, and finite-element displacement, equivalent strain, and von Mises stress fields. The accompanying surrogate model predicts the five nodal response channels from geometry and boundary conditions.

Dataset

Each sample defines a linear-elastic boundary-value problem and its FEM solution. Source cases include topology-optimized material layouts and, where available, fully solid counterparts with the same domain, loads, and supports. The numeric identifier in each filename identifies the source case, while the suffix identifies its material variant.

Geometry and discretization

The high-resolution grids subdivide each source element into 4 × 4 × 4 elements. Child elements inherit the binary material indicator. Physical array sizes vary with domain shape.

Coordinates and padding

Spatial array axes and sparse indices use z, y, x. Force and displacement components use x, y, z. An Nz × Ny × Nx element grid has (Nz + 1) × (Ny + 1) × (Nx + 1) physical nodes.

Target arrays include zero padding at the high-index end of each axis, to multiples of 16. Crop using valid_shape_zyx. Zero-valued responses cannot be used to identify padding or supports.

Reading a sample

import numpy as np

with np.load("sample.npz", allow_pickle=False) as data:
    nz, ny, nx = map(int, data["valid_shape_zyx"])
    fields = data["target"][:, :nz, :ny, :nx].copy()
    ux, uy, uz, equivalent_strain, vm_stress = fields

The scalar fields are recovered nodal invariants, not the six strain or stress tensor components.

Study population and partitions

The high-resolution study considered 76,901 audited samples. Displacement-RMS screening from 10−3 to 1 retained 75,114 cases. All 1,787 exclusions were above the upper bound. No audited case was below the lower bound. Screening selects samples without rescaling their stored fields.

Available variants and resolutions of a source identity remain in the same partition. The published manifests define the training, validation, and test sets. A division folder or a training_samples directory is not itself a train/test assignment.

Population and partition counts refer to the response-screened high-resolution study cohort.

FEM conventions and units

Reference solutions use trilinear hexahedral Q1 elements, eight Gauss points per element, and isotropic linear elasticity. Reference Young’s modulus is E0 = 1 Pa, Poisson ratio is 0.30, and artificial void stiffness is 10−6 times the baseline stiffness. High-resolution voxel spacing is 0.25 m in this benchmark unit system.

Stored displacements are in metres, strain is dimensionless, and stress is in Pa. Targets are not per-sample normalized or logarithmically transformed. The scalar invariants are computed at Gauss points, averaged over each element, and then averaged from incident elements to nodes.

These responses solve the linearized elasticity equations. Cases with large local strains are computational benchmark responses rather than physically validated large-deformation states.

Source data and boundary conditions

Domain dimensions, optimized geometries, load directions, and constrained components originate from NITO-3D. On non-cubic domains, axis-wise position mapping differs from the source’s common-length normalization. The released FEM fields correspond to the stored sparse nodal forces and support arrays.

Forces are nodal resultants, not pressures. Support indicators constrain individual displacement components. Zero displacement at a support does not imply zero stress or strain.

Padding, free degrees of freedom, and the material-region evaluation mask serve different purposes. Reproducing the FEM operator requires the original weak-material elements as well as the stored loads and constraints.

Surface representation and color scale

Original nodal values are sampled onto topology-preserving, simplified and Taubin-smoothed display surfaces. The source FEM fields are unchanged. Gray regions mark constrained surface nodes. Colors use log10(1 + q/q0), with q0 = 0.001 qmax. Ticks show original dimensionless field values. These display surfaces are not simulation meshes.

Model and evaluation

3DSolidFormer combines a residual 3D U-Net, global bottleneck attention, and task-specific local-window attention heads. Seven nodal input channels encode density, three force components, and three support indicators. The model returns the three displacement components, equivalent strain, and von Mises stress. Prescribed displacement components are set to zero.

Median network evaluation time was 0.412 s per high-resolution case in FP32 on one Tesla V100 GPU. Timing used 20 cases, two warm-up iterations, and five repetitions per case, excluding data loading and host-to-device transfer.
